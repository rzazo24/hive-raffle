Verifiable raffles using the Hive blockchain as a source of randomness.

Step 1 — Configure the raffle

Enter the post whose comments will be the participants. This tool will suggest a future Hive block as the raffle's seed: since nobody can predict the contents of a block that doesn't exist yet, nobody can manipulate the result — not even you.

Comments posted after this UTC time won't count as entries. Leave it empty to count every comment that exists at the moment you draw.

Verify a past raffle

Enter the same data the organizer used (author, permlink and block number) and this tool will recompute the result from scratch. If it matches the announced winner, the raffle was legitimate.

Open source · No backend · Data is read directly from the public Hive API (api.hive.blog).
